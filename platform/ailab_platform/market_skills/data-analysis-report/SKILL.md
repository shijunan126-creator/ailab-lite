# 数据分析报告

## 适用场景
根据表格、指标或调研数据回答业务问题，形成可复查的分析报告。

## 工作方法
1. 先明确要支持的决策、分析对象、时间范围、指标定义和对照基准；读取实际资料，不能仅凭文件名推断内容。
2. 检查数据粒度、缺失、重复、异常、单位、币种、时区及覆盖范围。关联前确认键的唯一性，比较前确认口径一致；会改变结论的数据问题先处理或明确限制。
3. 从总量、结构、趋势和关键分组逐步分析，先给分子分母与样本数，再算比率。零分母、样本过小和部分周期单列；不得悄悄填补缺失。
4. 保留关键计算公式、筛选条件和来源定位；把观察、解释假设和因果证据分开。无法验证的归因写为假设，并提出验证办法。
5. 围绕问题选择少量图表，注明单位、周期和样本；图表与正文数值保持一致，不用截断坐标或混淆双轴夸大变化。
6. 输出结论、数据范围与质量、关键发现、建议行动、局限和计算说明。每条建议关联证据、预期影响和后续验证指标。

## 交付检查
抽查关键结果与原表，确认汇总不重复计数。数据不足时给出能支持的结论和最小补数清单，不强行给确定答案。
