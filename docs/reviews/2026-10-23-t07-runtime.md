# T07 / T19 集成与最终验收

代码基线：运行恢复/多模态为 `4f9f3cb392bb44709c91ea08cae33d83238783e7`，交付边界补充为 `6aef7cd`，包含T19合并 `a1547fe`。本轮由主Agent独立完成，没有启动或恢复subagent，没有推送、PR或生产部署。原T07 worktree的未提交实现先完整导出到本机补丁，再三方应用并语义解决与OCR、Skills的冲突；源worktree保留原状，不作为当前验证副本。

## 行为

- **持久OCR**：扫描READY与OCR任务同事务，经 `stage_job(kind=ocr)`、JobEnvelope、API claim与ACK、Worker传输ACK。忙时保留任务重投，超时和完成后重复消息跳过。每页用固定call_id及file_job账本，OCR结果不覆盖原生提取文字；T07结算新增attempt字段后，OCR同样传冻结身份。
- **平台运行恢复**：0019接在0018后；每个模型响应、工具开始/结果写gzip checkpoint与step CAS，保留最近两份。不可确定是否完成的exec不重跑，给模型明确工具结果；交付按平台调用位置幂等。调用身份是Run + 模型步数 + 本步序号，不能相信上游call id跨响应唯一。工具结果仍携带上游id满足模型协议。
- **写入栅栏**：状态、事件、checkpoint、pause、摘要、预留与交付必须持有当前attempt；检查与写入同事务。旧拼写/status不能绕过。晚到结算只接受预留时冻结的attempt，可以在失去租约后补账。暂停时立即结束attempt，旧写入不等到传输ACK才失效。
- **暂停与续跑**：ask_user前强制保存工作区、释放沙箱，任务不占Agent槽。答案绑定平台question id，新续跑任务使用新job id，旧ACK不能删除它。回答及手动恢复在用户锁内重查额度、并发、会话存活和checkpoint；暂停会话不允许插入新一轮，删除会话/项目会取消暂停任务。
- **租约与工作区**：60秒独立续租，410中断并自动续跑一次；再次失败等待用户。工作区不可变快照，按实际变更标记判断是否落后，避免每次checkpoint都错误警告快照过期。等待问题超时转interrupted后仍可回答；普通中断超时取消。
- **多模态**：只读取API授权的归一化图片，vision候选才携带图片；无vision/图片不可读时使用OCR文本或明确不可读状态。图片预算独立估计，不把base64当文本计费。checkpoint只存文件引用，恢复时重新授权读取，避免每步复制图片。离线模型也接受multipart文本回退。
- **Portal**：等待与中断的SSE在交付完已有事件后关闭，回答后携带上次seq重新跟随同一Run，避免重复文本。桌面、手机、刷新后和问题超时后的回答入口均可用；有待回答问题时不显示无效的“继续”。
- **清理**：终态事务给最多两份checkpoint冻结7天过期时间，清理走 `(expires_at,run_id,step)` 索引；删除意图与元数据同事务，物理对象沿既有生命周期重试。临时对象/工作区的GC沿原有宽限与预算执行。
