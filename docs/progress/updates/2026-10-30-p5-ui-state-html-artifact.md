# 2026-10-30 P5 收尾、控件状态持久化与 HtmlArtifact

分支 `feat/frontend-genui`，base `origin/main@97793e6`，未提交。用户本轮要求：完成控件状态跨刷新、性能闸门、P5（清空 legacy、启用 preflight、加 CSP）、P4-H（HtmlArtifact）、P6 复评和 PostgreSQL 全套，最后由 Codex 部署。GenUI chunk 超 60 KB 由用户接受，不在本轮处理。决定见 [ADR 0027](../../architecture/adr/0027-portal-ui-stack-and-send-flow.md)、[ADR 0028](../../architecture/adr/0028-generative-ui-openui.md)，陷阱见 [HANDOFF](../../../HANDOFF.MD)。

## 做了什么

**控件状态（ui-state）**
- 后端：迁移 0039 新增 `runs.ui_state`，接口 `PUT /v1/runs/{id}/ui-state`，可能返回 204/401/404/422/429。
  - 校验：v=1；块编号为 "0".."N-1"；最多 64 项；键名不超过 120 字；值只接受标量或 `{value, componentType}`；整体不超过 16 KB。
  - 限速：每用户 120 次/分钟。
  - 输出：会话详情和分享视图返回 `ui_state`。
  - 详细记录：[后端记录](2026-10-30-genui-ui-state-html-backend.md)。
- Portal：
  - 存储内容：Tabs、表格排序、图例和绑定变量都存进 OpenUI store，键名按语句名。
  - 保存时机：变化后 600ms 合并保存；离开页面时用 keepalive 发出。
  - 本页优先：本页较新的状态优先于先前取回的详情。
  - 分享和打印：从保存的状态开始，只读。

**HtmlArtifact（P4-H）**
- 组件：`HtmlArtifact(title, document ≤24k, fallbackText ≤2k)`；单块上限放宽到 32k 字。
- 运行环境：同源 `app/frame/[kind]` 路由，iframe 为 `sandbox="allow-scripts"`，文档经 postMessage 投递。
  - 书写中（preview）：CSP 只放行壳脚本的 hash。
  - 完成后（run）：CSP 为 `default-src 'none'`，无网络。
  - 被截断：显示“页面没有写完，未运行”。
- 页面行为：
  - 跳到外部地址时被停止，提供“重新运行”。
  - 离开视口约一屏后卸载，回来时重建。
  - 跟随主题变量。
  - 复制和打印输出 fallbackText。
- 交付的 HTML 文件预览同样改走 frame 路由，`kind=doc`。
- 准入：`AILAB_GENUI_HTML_ENABLED` 默认开启，经 `/v1/auth/me` 的 `features.genui_html` 告知 Portal。

**数值与提示词**
- Metric、Table 和三种图表新增可选 `decimals`（0–4）。
- P6 第二轮（[评测报告](2026-10-30-genui-real-model-eval.md)）的失败按根因修复，不靠再加禁止句：
  - 数据来源：原数据写成对象数组，表格、图表、Metric 和文字都从它取值；Text、Callout、hint 和 delta 里的数字也用表达式拼出。
  - 结论：有界面块时，结论写在块里的 Text/Callout 中，名称、数字和比较方向由 `@First(@Sort(…))`、三元表达式得出；块外文字不写派生数和名次。第二轮的错误标签、错误百分比都出在手写的正文里。
  - 表格结构：rows 用 `@Each(items, "x", [...])`；`+` 不连接数组（`rows + [total]` 求值为 0，第二轮的筛选表格因此为空）；合计放在表格外。
  - delta：定义为相对上一期的变化率（%），显示为一位小数加 `%`，正负两侧的 .5 都远离零舍入。
  - HtmlArtifact：示例给出完整的 `root = Stack([page])`，不用 html 代码围栏。
  - 不加无需求的按钮、加权评分、稳定性排序，也不重复 Markdown 表格。
  - 第三轮后补充：
    - 字符串拼接里的算式整体加括号。OpenUI 求值器把 `"增加 " + b - a` 静默算成错数，不报错。
    - 下标取出的就是对象，不再套 `@First`。
    - PieChart 只收数值数组，不收 Series。
    - 开头示例改为一个主图加表达式结论。
- 运行时：求值后形状不对的表格或图表数据显示“数据格式有误，无法显示”，书写中不提示，复制时省略。之前会显示成空表，或者行错位的表格和图。饼图要求每个标签对应一个非负数值，缺值会让整体比例失真。
- 复制：之前读的是未求值的解析树，表达式算出的表格在复制时会抛错，`$变量` 的结果也是空的。现在按页面相同的方式求值，并使用读者当前的控件状态。
- 提示词已重新生成：11134 字，sha `56daecf8…`。

**P5：清空 legacy、preflight、CSP**
- 样式分层：
  - 删除 `legacy.css`，旧样式按区域并入 `styles/base|shell|chat|library|pages.css`。
  - 与 `app.css`、`genui.css` 同在 components 层。
  - Tailwind preflight 在 base 层启用。
  - 删除旧名别名 token。
- 删除的规则：迁移前已在所有元素上被覆盖的声明，以及 37 个不再使用的类（全量扫描复核后已无死类）。
- 同层后的冲突处理：
  - 以“针对同一元素的更具体规则代表设计意图”为准。
  - 旧规则压过重建组件的个别情况改回重建值（侧栏链接字重；项目菜单按钮与会话菜单按钮一致）。
  - 依赖旧文件先后顺序的覆盖改为显式选择器（`.modal.search-dialog`、`.modal-scrim.search-scrim`）。
  - 恢复模板拼出的文件色块 `tone-*`。
  - 删除按钮悬停显示危险色（`danger-hover`）。迁移前这条被通用的 `.icon-btn:hover` 盖住，属于既有缺陷。
- Markdown 结尾统一保留自然下边距（删除 `.md > :last-child{margin-bottom:0}`）。迁移前，以段落结尾的回答实际就是这样显示的，现在以表格或代码结尾的回答也一致。
- preflight 去掉的标题粗体、列表标记、行内图标、输入框外观在 `base.css` 顶部补回。
- CSP：
  - `proxy.ts` 为每个页面生成 nonce：`script-src 'self' 'nonce-…' 'strict-dynamic'`、`object-src 'none'`、`frame-ancestors 'none'`、`frame-src 'self' blob:`。
  - layout 里的内联脚本带 nonce。
  - PDF.js 关闭 eval。

**性能**
- 平滑文字的放出时长从 120ms 改为 80ms，原因是“delta 到可见”上次实测 164ms，超过 150ms 预算。
- Composer 模式选项改用模块常量，历史轮次不再随每次 turns 更新而重渲染。

**样式并层（P5）**
- 方法：同一份代码出两份生产构建，一份迁移前（13101），一份当前（13100），连同一个后端栈。在同一 DOM 上逐元素比较计算样式。

- Console：Portal 页面无 CSP 违规。frame 内只有预期中被拦截的网络和存储请求。

**性能（`platform/scripts/bench_portal.py`，与 main@97793e6 成对比较）**

每个 CPU 档位 3 次，取中位数或最坏值，SSE 实测约 39 字/秒：

| 指标 | 1× | 4× | 预算 |
|---|---|---|---|
| 输入 p95 | 16.5 ms | 19.2 ms | ≤ 基线 ×1.1（18.26 / 21.12） |
| DOM 节点（500 轮） | 733 | 733 | ≤ 888 |
| >50ms 长任务 | 0 | 0 | 0 |
| 帧 p95 | 16.7 ms | 16.7 ms | 16.7 / 33 |
| 流式期间历史轮次内容 mutations | 0 | 0 | 0 |
| delta→可见 p95 / max | 117.4 / 118.9 ms | 118.6 / 121.4 ms | ≤ 150 |
| entry JS gzip | 73.7 KB | — | ≤ 141.7 KB |
| GenUI chunk gzip | 85.7 KB | — | 60 KB，**不达标**，用户已接受 |

- 上一次测得 delta→可见 164 ms，超出预算。把平滑文字的放出时长从 120ms 降到 80ms 后达标。

**P6 真实模型评测**：见[评测报告](2026-10-30-genui-real-model-eval.md)第三轮、第四轮。
- 本轮修复后已不再出现的问题：错误的数组拼接、对象再套 `@First`、饼图传 Series、原始 html 围栏、求值后形状错误的块。
- 编辑成功率 83–100%，闭合块合法率约 97%。
- 严格数据一致性 47.8%，未达 100%，**P6 未通过**。剩余失败多数是块外手写的数字或结论（即使数值正确），少数是推理错误，例如取错项、做了没要求的统计检验。
