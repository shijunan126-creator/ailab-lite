# 网页图片短引用与无落盘代理

## 范围与基线

用户授权实施前序讨论的推荐方案：模型使用短 ID、只存地址元数据、按地址去重、候选到期清理、采用的图片随消息引用保留、缩略图优先和按需流式代理。分支 `feat/web-image-refs`，基线 `origin/main@e3122ae326b3f0fec5c3daf29fc7f2c4cba88db4` 加本轮工作树差异。用户随后追加授权提 PR、CI 通过后合并并增量部署；主工作区既有修改未动。

## 最终合同

- API 在 `web_images` 按原图 URL 的 SHA-256 唯一索引去重，生成 `img_` 加 12 位随机字符（总长 16）的 ID；不按图片内容去重。按 URL 摘要一致顺序加锁、事务 upsert，重复/并发搜索复用 ID，搜索结果顺序保持。Agent 不直接写数据库：通过带服务 scope 和 attempt 围栏的内部接口登记，成功后只向模型返回 ID、标题/尺寸与来源网页，不返回原图或缩略图 URL。
- `web_image_refs` 绑定 Run。候选默认 24 小时；活动/暂停 Run 的候选延期，保证恢复后工具结果仍可用。`agent.message` 和终态 summary 中实际引用的 ID 转为无到期引用，同会话后续回答可以继续引用。历史过程里明确使用过的 ID 也保留，不仅限最终 summary。
- 分叉复制已采用的引用；源失效清理、会话最终 purge 释放本轮引用；会话软删立即拒绝访问，恢复期内仍保留元数据。最后一份引用释放后按维护批次回收。每轮维护最多各处理 `gc_batch_size` 条过期引用/地址，不扫描整表，不另起后台服务。
- 新 ID 必须校验当前用户的存活会话引用；分享额外携带 `share_id`，只允许分享路径中已采用的图片，撤销/停用立即拒绝新的接口请求。ID 本身不是权限。来源从受权的元数据接口按需取得，模型无需重复填写图片来源。
- 列表懒加载缩略图（没有则原图），点击大图才请求原图；图库折叠项不请求图片。代理在取到至多一个 64 KiB 块并校验文件头后开始发送，持续流式转发；不写对象存储、不记图片派生容量账本、不持久化图片字节。保留公网 DNS/IP 固定与逐跳检查、TLS 验证、格式限制、每次 10 秒总超时、8 MiB 上限和每进程 4 条活动传输。并发槽覆盖等待上游、传输与客户端背压，退出时关闭流与客户端。
- 原图在发头前失败可回退缩略图；发头后中断由大图组件请求一次缩略图 fallback，再失败则占位。浏览器私有缓存 300 秒；URL 不是内容身份，不再声明 immutable 或按 URL 伪造内容 ETag。原站删图/变图会影响历史图片，浏览器已有副本也可能继续显示到缓存过期。
- 新链路不需要 `AILAB_WEB_IMAGE_KEY`，secure 不再要求它，secrets 脚本不再生成；Agent 不再挂载它。API 可选保留旧 key，仅用于已有签名路径的兼容读取，也不再缓存图片。旧签名仍沿用既有 capability 语义，不能宣称它获得了新 ID 的逐会话权限。已有图片缓存不做历史批量清理，继续按原回收合同到期释放。
- 迁移 `0063` 新建地址/引用表及查找、过期和反查索引；upgrade/downgrade 不改旧消息。无新增依赖。

## 验证与性能

本节为本轮检查，前序 PR #165 的证据不计入本轮验收。

- Ruff check/format、Portal 267 项及生产 build 通过；GenUI catalog 从 Portal 重新生成。浏览器检查发现大图来源徽章误用照片上的绝对定位，已改为大图说明行中的普通链接，并重新 build/检查。
- Python SQLite 全套首次 2867 项：2574 通过、265 跳过、28 失败；PostgreSQL16/Redis 全套首次：2749 通过、88 跳过、30 失败。缺 GNU `stat/find` 路径、未构建本检出的 Office reader，以及新增迁移后测试仍写死旧 head 是共同原因。配置 GNU PATH、构建 pinned runtime、更新迁移链期望后，SQLite 的 28 个失败项全部通过，PG 原 30 个失败项复核通过。不是最终 SHA 的整套重新运行。
- PG 追加 EXPLAIN 检查曾因 `str(SQLAlchemy Row)` 截断计划文本而误报失败；改为结构化取出列后序列化，不改查询或放松索引要求。最终双库索引检查与图片回归见下方收尾结果。
- 新回归覆盖：登记幂等/attempt 围栏、并发逆序批次复用 ID、模型不见原图 URL、来源元数据、跨用户拒绝、分享快照/撤销/软删、候选到期、活动候选延期、分叉引用/最后引用释放、类型/原图超限回退、增量读取及断开关闭资源。`test_prefix_cache.py` 记录实际 AgentLoop 请求，检查图片工具结果追加且不改既有消息/工具。
- EXPLAIN 在两库各 10,000 条地址/引用、ANALYZE 后检查 URL 查找、地址到期、图片引用反查和候选到期索引；这不是百万级容量或并发压测。维护成本受批次限制；单条传输应用层按 64 KiB 分块，非完整 8 MiB 缓冲。回归确认打开时只读取一块、断开后关闭上游；没有把传输块大小当作进程 RSS 上限，也没有测整栈 CPU/RSS 容量。
- 真实 DeepSeek Flash + SearXNG + 独立 API：准确使用短 ID；一次主流程调用搜索、组件说明与网页读取后成功配图，返回 JPEG 40,220 bytes。下一轮不重新搜索，复用相同 ID 并正常显示；该轮缓存 12,160 / 12,327 = 98.65%。首轮搜索共 6 次模型调用（含标题），总体缓存 45,440 / 50,562 = 89.87%；新增工具/网页结果较大时单次比率下降，不宣称每次都达到 95%。连续三个可比较主请求保留前缀；独立自动标题调用不应与主请求做相邻比较。
- 本机代理 Fake-IP DNS 返回 `198.18.*` 时，首次真实图片取图被正确拒绝。仅临时验收进程改用 Google DoH 返回真实地址，仍执行生产公网检查、固定 IP 和 TLS 校验，没有放宽产品安全条件。Agent 的网页读取仍可能受本机 DNS 限制，不能把此环境适配称为产品修复。
- 内置浏览器报告 unavailable，按 HANDOFF Playwright 路线使用真实 Chromium、生产 Portal 和隔离 API，检查 1280/390 × 浅/深色、图片来源和大图打开/关闭，图片 naturalWidth 非零、无横向溢出、无 pageerror。只覆盖本功能，不代表全站或其他浏览器验收。临时数据、脚本、日志和截图均在仓库外，用后清理。
