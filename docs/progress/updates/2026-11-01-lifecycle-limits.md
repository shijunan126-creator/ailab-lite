# 生命周期收尾：停用、资产回收、回收站预览、定时任务规范（2026-11-01）

分支 `feat/lifecycle-limits`，base `origin/main@ada5f60`。用户批准[删除审查](2026-11-01-deletion-review.md)后续方案并要求设计、实现定时任务规范。后端由 Codex（gpt-6.1-sol medium）实现，Claude 审阅、补修并完成 Portal 与 E2E。

## 用户决定

- 删除来源对话时保留用户显式保存的记忆事实（维持 ADR 0019）。
- 回收站文件本人可读：保留，并在回收站内提供只读预览与“恢复”。
- 删除定时任务不取消已开始的那一轮。
- 真正的账号删除（4b）暂不做，等有实际需要再单独立项并先写 ADR。

## 实现

- **停用账号**：同一事务吊销会话、取消该用户所有未结束 Run（`reason=user_disabled`）和排队消息。此前停用后任务仍继续消耗模型额度。
- **模板/品牌素材回收**：新表 `run_asset_refs` 记录 Run 冻结的模板与品牌文件（创建、排队、重试/编辑、分叉、品牌首次快照时登记；迁移回填）。reaper 每轮最多 `gc_batch_size` 个：软删且无引用的模板、已退役且无引用的品牌素材，在对应锁内复核后以 tombstone 清除，释放配额与对象。此前删除的个人模板永久占用资料库配额。
- **回收站预览**：回收站点文件打开只读预览，无对话/分享/版本操作，顶部“恢复”。
- **定时任务规范**（原有：每人 5 个、最频每天一次、额度与并发限制、全局开关）：
  - 可选结束日期（不结束/一周/一个月/三个月/半年后），过期自动停用；
  - 上一轮未结束则跳过本轮，不重叠；
  - 连续 3 次结果未查看且最早一次已满 7 天，自动暂停；等待回复超过 7 天无人理会也暂停（Claude 补修，否则会无限跳过）；
  - 连续 3 次失败自动暂停；
  - 每次自动暂停发一条“定时任务已暂停”通知，列表显示原因；重新启用或修改时间/结束日期清零。
- 迁移 0045：`run_asset_refs`、文件回收候选索引、`scheduled_tasks` 四列（`ends_on`、`paused_reason`、`recent_run_ids`、`failure_streak`）。
