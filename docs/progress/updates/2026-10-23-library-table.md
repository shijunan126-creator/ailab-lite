## 根因与结果

原实现只有“名称”表头，正文为各自独立的圆角 flex 行，无行边框；大小、时间、项目混在名字下方，因此表头和正文看起来断开，无法按列扫描。

改为一个原生 table：共享列布局，名称、大小、创建时间、所属项目分别对齐；表头底色与逐行细分隔延续到末行。项目内列表省略所属项目列；回收站显示保留时间。长名称截断并保留 title；窄屏收起辅助列，在名称下面保留大小、时间和项目入口。预览、版本/技能/扫描状态、收藏、菜单、下载、批量选择沿用原业务逻辑，键盘 focus 与展开菜单也能显示操作。

仅变更 DOM/CSS，不引入依赖、请求、查询或后台任务；列表数据上限与分页不变。未新增渲染测量循环。未测目标机器 CPU/RSS，本轮不涉及后端性能或生产容量声明。
