## Debian快照获取修复

固定快照批量下载持续503/504（含No healthy backends）；原APT获取随后cgroup OOM。单包探针可成功，不能据此把批量故障认作包版本错误，也不能证明APT内部具体内存保留链。新下载器由签名快照索引解析完整版本/大小/SHA256，先取`deb.debian.org`相同pool路径的字节，再尝试固定快照URL；每包完整校验后才离线APT安装。没有更新包版本、改快照日期、关闭校验或加内存。

下载顺序执行，64KiB缓冲、每socket20秒、总20分钟、每包最多两个不同来源；闭包最多1000包/2GiB、单包200MiB。哈希/预算/本地文件系统错误直接失败，不作为网络重试。实际368包约700MB校验成功，完整生产镜像构建通过；生成的capabilities Dockerfile摘要已同步。**签名索引仍依赖快照源**，索引不可用或两个来源均无同字节包时明确构建失败，不保证外部服务永远可用。
