## 实现与验收标准

- “详情”按钮复用当前会话侧栏：桌面右侧、手机保留 tabs；文件/来源/详情共享容器，关闭非当前 tab 不抢选中项。
- 左上返回按钮收起侧栏，不卸载聊天、不打开新对话；手机浏览器 Back 与 Escape 同样关闭侧栏。焦点返回不滚动聊天；桌面恢复原宽度后还原打开前位置。
- 详情可滚动查看完整时间线；每次打开从请求/任务开头展示，不再按事件数自动滚到结尾。复用原详情渲染，挂载时读取Run/事件，卸载时取消请求与SSE，忽略过期响应。历史独立链接保留，返回所属会话。
- 没有新增后端接口、SQL、依赖、后台任务或轮询；仅用户打开详情时增加原来独立详情页同类请求，切走详情即停止订阅。未做目标机容量测试，不声称性能已量化验收。
