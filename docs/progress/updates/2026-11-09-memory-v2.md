## API 契约偏差与风险

- 新 `/view`、`/items`、条目 PATCH/DELETE、`/edit` 已实现；DTO 已写。`core` 按 page/priority，`pages` 按 count/name；review 仅条目列表。
- 选择链式报告：`report.next_id` 指向后批，末批报告包含累计 `runs_seen`/`added`；链末发布、崩溃恢复与重复执行仍需回归，**目前不能向 Portal 保证完成语义**。
- `/v1/memory/summary*` 路由已移除，但旧摘要存储及部分内部辅助函数暂保留。旧测试未完成迁移。
- 单条来源查找存在 N+1；实体派生更新存在重复扫描，未达 §14 性能验收。没有新模型或产品依赖，向量配置未开启。
