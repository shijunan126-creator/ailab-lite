## 评测

提取/检索/触发评测行为基线 `4bb98f9`；之后只修改调度与常驻投影/追加消息路径，未改变提取、查询打分或§7.3主提示词。真实缓存六场景在 `2b3bec2` 上重新运行；评测脚本更新后仅对原始usage重算新判定，不重选调用。

### 合成检索及时间

`scripts/evaluate_memory_context.py --v2` 使用实际 `search_memory`，含条目库与数据库历史通道，不再是单文档关键词命中测试。30条相关查询、10条无关查询：Recall@5 **1.0000**、MRR **0.9833**、弃答率 **100%**；时效 **3/3（100%）**。预期条目和 Run 身份保存在合成 fixture，无真实用户内容。

### 真实触发

配置的实际模型为 OpenCode Go 网关上的 DeepSeek V4.1 Flash；加载个人 catalog 和所指环境文件，禁止 mock 回落。`scripts/evaluate_memory_trigger.py` 使用生产 Chat 主提示词和完整工具 schema，只评第一模型调用的工具决策，不执行查询后的完整答案链路。60个原样 fixture，未修改测试样例。

### 真实前缀

`scripts/evaluate_memory_prefix.py`：实际 AgentLoop、实际序列化provider payload、生产提示词及ABI2工具；Chat/Work×不变/条目变化/跨日，共六场景，每场景四轮，串行24次真实调用。条目在第2→3轮改变；跨日模拟记忆时钟。API/Broker为内存替身，不是服务/沙箱联合验收。无重试、无填充、未删推理内容、未挑选调用。

### 性能与成本边界

Mac本机、SQLite内存合成库，2000条目+400历史，12次实际检索：冷135.4ms，热中位12.7ms、最大13.3ms；累计CPU0.278秒，进程峰值RSS98.3MiB；条目/历史缓存约5.41/1.47MB。两个分词缓存各16MiB预算；进程峰值包含解释器、SQLAlchemy与合成库，非生产API常驻RSS验收。结果受本机负载影响。

真实历史本次15次调用/111轮约0.135次/历史轮；这是离线提取+一次Dreaming，不能当作交互每轮平均工具调用。触发评测只统计首次调用决策；未测完整交互工具成本与300真实用户整夜资源曲线。没有新运行依赖；正常模型请求不增加网络调用，网关故障才写冷却信号，自动任务领取读取一次信号，均离开API事件循环。
