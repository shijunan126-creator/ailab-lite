## 评测

### 合成检索及时间

`scripts/evaluate_memory_context.py --v2` 使用实际 `search_memory`，含条目库与数据库历史通道，不再是单文档关键词命中测试。30条相关查询、10条无关查询：Recall@5 **1.0000**、MRR **0.9833**、弃答率 **100%**；时效 **3/3（100%）**。预期条目和 Run 身份保存在合成 fixture，无真实用户内容。

### 真实触发

配置的实际模型为 OpenCode Go 网关上的 DeepSeek V4.1 Flash；加载个人 catalog 和所指环境文件，禁止 mock 回落。`scripts/evaluate_memory_trigger.py` 使用生产 Chat 主提示词和完整工具 schema，只评第一模型调用的工具决策，不执行查询后的完整答案链路。60个原样 fixture，未修改测试样例。

| 2 | 29/30，96.7% | 1/30，3.3% | 达标。只调整 §7.3“不查优先、时间词本身不等于历史查询”。 |

### 本机真实历史

用户恢复原本停止的 VM 后，仅 `docker cp ailab-local-api-1:/data/platform.db /private/tmp/memv2-eval/platform.db`。复制库0063→0064，quick_check=ok；未写容器。只在副本主账号做完整提取及一次真实 Dreaming。

第一轮：111轮，41条；逐条质量模型复核标出8条测试/复现相关记忆。根因是测试排除只覆盖模型候选，未覆盖 artifact 表生成；修复共同的来源排除后，从新复制的0063库重跑，未手工删条或改历史。

最终：111轮、8个提取批次、待处理0；**23条，全为archive**：interest14、project5、artifact4；preference/fact/reference/core均0。15次已计量模型调用，prompt48,594、completion6,841；副本一次完整提取+Dreaming约115秒。70轮被标记为测试/开发等排除来源。逐条复核23/23，**测试/复现来源产出记忆0轮，未标出编造**；2条兴趣长期价值偏弱。没有据问题主题推断职业身份；这不是独立人工标注质量分数，也不是通用提取准确率。

`/private/tmp/memv2-eval`（副本、原文、候选、复核内容与脚本）已完整删除。仓库不保存个人内容、凭据、原始回答或日志。

### 性能与成本边界

Mac本机、SQLite内存合成库，2000条目+400历史，12次实际检索：冷135.4ms，热中位12.7ms、最大13.3ms；累计CPU0.278秒，进程峰值RSS98.3MiB；条目/历史缓存约5.41/1.47MB。两个分词缓存各16MiB预算；进程峰值包含解释器、SQLAlchemy与合成库，非生产API常驻RSS验收。结果受本机负载影响。

真实历史本次15次调用/111轮约0.135次/历史轮；这是离线提取+一次Dreaming，不能当作交互每轮平均工具调用。触发评测只统计首次调用决策；未测完整交互工具成本与300真实用户整夜资源曲线。没有新运行依赖；正常模型请求不增加网络调用，网关故障才写冷却信号，自动任务领取读取一次信号，均离开API事件循环。

### 慢socket测试

原 `origin/main@df83d8e` 单例在PG上12次自然运行均通过，不能称自然重现了旧flake。受控将HTTPX冷transport初始化延迟0.6秒，在未改动main测试和0.5秒deadline下复现同一 `seen=0` 失败：SSL/proxy配置建立发生在请求发出前，计时先耗尽，服务没收到请求不代表deadline失效。当前测试只提前构建transport，仍用真实TCP、仍断言deadline及1次请求，不放宽阈值、不加重试；同一初始化延迟下通过。
