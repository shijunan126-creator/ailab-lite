## API 契约偏差与风险

- 新 `/view`、`/items`、条目 PATCH/DELETE、`/edit` 已实现；DTO 已写。`core` 按 page/priority，`pages` 按 count/name；review 仅条目列表。
- 选择链式报告：`report.next_id` 指向后批，末批报告包含累计 `runs_seen`/`added`；链末发布、崩溃恢复与重复执行仍需回归，**首轮不能保证；本轮已补持久链末发布/恢复和重复执行测试**。
- `/v1/memory/summary*` 路由、摘要 ORM/存储/辅助函数已移除；旧测试迁移见下文。
- 管理接口来源与实体来源聚合已批量化，双库 EXPLAIN 和查询数回归见下文。没有新模型或产品依赖，向量配置未开启。
