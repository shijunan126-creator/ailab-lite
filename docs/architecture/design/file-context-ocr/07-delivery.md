准确性数据集候选100页：原生/扫描中文与英文、混合页、表格、歪斜、低清、无文本/空白、旧OCR错层；人工真值计算CER/WER，关键数字与表格单元格单列准确率。质量阈值在有代表性样本后定版；在此之前不能承诺“更准确”。真实模型/目标OCR引擎合同必须检查请求媒体、usage、来源与结果；mock只验流程，不能代替识别质量或付费模型保真。

实施完成需按AGENTS做lint、完整Python双库、Portal test/build及真实浏览器；外部OCR/模型缺条件明确未验。本轮是设计，仅做源证据和文档一致性检查，不为文档改动启动业务栈或跑全产品套件。


## 已定方向与剩余决策

已定方向以[总览](README.md)为准：Chat预处理/准入，Work按需自主操作，输入框每轮5张独立图片限制，图片按vision能力分流，tool/skill搜索加载，RapidOCR＋昇腾NPU优先，缓存与删除谱系统一。与最初单篇稿不同，Chat不靠多轮文件工具处理超大文档，也不把CPU作为首选。

待定：OCR积分/配额政策；Chat长度/页数/扫描页数候选门槛；目标NPU型号/分配槽位、版本组合和并发；复杂表格/公式增强解析是否首版加入。阶段依赖是设计安排，不是本轮实施许可。
