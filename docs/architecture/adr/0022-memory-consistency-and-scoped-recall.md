# ADR 0022 · 有来源、可隔离、可续的记忆

状态：采用并实现（2026-10-28）。用户已授权完成记忆系统缺陷修复及架构、体验补齐；已授权验证后提PR并修复直到merge，不包含部署。取代前轮仅审查边界，不恢复已取消的“临时对话”产品入口。

采用现有五服务和双库，保留有界账号事实文档，不引入向量服务或新重型依赖。统一模型可见性和写入政策；项目事实严格隔离，普通对话不读项目事实。账号偏好可用于项目，项目可设仅本项目。独立控制长期记忆、历史引用与自动写入。

后台以run为持久处理单元，保存已抽取候选及消费进度；先短事务固化输入，再事务外调用模型，最后以claim/版本/来源/墓碑重新校验提交。事实替换及全部失效是不可拆的一组。每次实际模型调用单独进入统一reserve/settle账本，失败和重试也记账。

删除传播覆盖episode、vector、待处理候选、整理快照/计划与工具重放；保存事实正文仍沿用ADR0019的独立删除语义，但清除来源引文。用户删除事实后清除所有派生副本，仅留hash墓碑；撤销采用当前结果的版本校验，不能覆盖后续编辑或复活已删数据。

在线事实选择和历史检索均有明确范围、token/字符预算、弃权和来源。历史详情按需读取；时间查询支持观察时间与有效时间区间，旧状态保留供明确历史查询。敏感推断进入待确认，不能因助手猜测成为已确认事实。

验收：前轮13个合同探针全部转绿；加入项目隔离、迟到/同时间戳/预算续批、并发claim、删除/禁用竞态、计费、来源/撤销和离线golden；全量双库、迁移升降、Portal构建及真实浏览器交互。性能必须验证数据库不跨模型等待持写锁，后台批次/列表有界，并记录2CPU/8GiB目标外的测量边界。
