# ADR 0034：安全原件就绪与按需派生

状态：已本地实施，未合并/部署。新Run已默认V2，旧Run仍冻结V1目录。下文标记“未验收”“尚未默认”的段落是2026-11-06实施过程的历史阶段，不再代表当前状态；最新基线与实际边界见[真实模型workflow复核](../../progress/updates/2026-11-07-real-model-document-workflows.md)及[本地收尾](../../progress/updates/2026-11-06-document-input-final-acceptance.md)。完整合同以[文件输入设计](../design/2026-11-05-chat-document-input.md)为准。

## 决定

新普通输入在API创建时记录`input_lifecycle=2`。Worker在安全扫描、受限类型/压缩包检查、摘要与大小核验后即可发布`FileStatus.READY`，此时native_text/page_images/ocr_text各自为absent。上传不提取正文、不复制派生缓存、不缩略图、不预热或租Office沙箱、不生成语义摘要。实际识别的格式由API校正MIME。模板/品牌/技能专用入口和用户成品保持各自必要流程。

既有无v2标记的排队任务沿原路径恢复；只有这些旧任务允许在扫描通过、解析尚未结束时预览。v2文件的scan clean本身不能绕过类型/完整性检查提前启动派生。不是把旧文件全部重新扫描或解析。

Work可立即取得安全原件；Chat发送和显式消费才请求持久native job，图片只有消费时准备所需表示。native失败不改变原件安全就绪状态，也不返回假空白。旧`read_library_file`可通过新增native-text文件依赖等待原生准备，已付费调用/原工具目录保持，恢复后追加真实结果。

Native每代只存manifest和规范UTF-8正文，索引用字节范围与逐块SHA256定位；Office仍承认首次整包解析成本，普通文本在Worker受限子进程内流式读取，超200000字符失败而非截断。源版本、job/attempt与完成请求指纹共同围栏发布；两个暂存资产与索引/元数据在同一业务事务发布。

容量迁移先持久增量回填。启动/周期维护只回收未发布的失败/崩溃写入，发布缓存的TTL回收须等全部生产writer记账和业务失效接通。正常失败由API确认未发布后立即删除暂存；响应丢失但已发布的资产不能当作失败清掉。不得把backfill_complete当作所有新旧生产路径已受容量控制的证明。

## 与旧合同的关系

取代ADR0026中“文件安全可用依赖上传全文准备”的旧实现含义；保留权限、来源、旧工具等待与恢复合同。新Chat目录、显式OCR、输入分档、Work模式隔离和浏览器唯一执行权仍需继续实施，不能用本ADR提前宣称其已完成。真实上传/按需准备与分组回归证据见[实施记录](../../progress/updates/2026-11-05-document-input-lifecycle.md#安全入库与消费准备已接通2026-11-05续作)。

## V2目录的接入边界（2026-11-06）

新目录用API拥有的run选项选择，旧checkpoint继续固定原schema。原生读搜/导航与模式围栏已接通，目录尚未默认启用；显式OCR与浏览器操作及完整资源合同完成后再切换新run。按模式指南从build.py生成独立Agent资源，旧沙箱技能包不改，避免仅修改技能文案也使旧run包哈希失效。详见统一实施记录。

## Work V2接线（2026-11-06，未验收）

新Work由API选择V2目录并只交原件引用；受限工作区图片经当前lease准备，API调用原有OCR执行器。operation/lane持久记录身份、绝对预算和取消/回收围栏，正常OCR会话保持暖进程。当前只接新Work OCR，文件OCR/native/render尚未统一调度；Chat默认目录尚未切换。本组按用户要求先实现，最终集中验收。


## 原生范围合同（2026-11-06，未验收）

V5长PDF先probe，指定范围才提取；真实页导航不依赖正文。范围缓存独立于基础索引指针，并绑定基础代际；Word/Excel仍整包解析后选结构范围，报告完整来源成本。范围原生任务进入render持久槽，发布沿两对象容量/尝试围栏，文件等待只追加恢复结果。默认Chat目录及全生产资源/浏览器合同尚待接齐；详细实现与未测边界只维护在统一实施记录。


## V2输入装配（2026-11-06，未验收）

发送前准备使用持久发送身份并冻结整份inline/按需策略；首个重型工作起点与600秒截止进入Run/排队快照。正文总预算取24K token与20%模型输入预算较小者，文档inline图总计8，导航全轮2000token；不按物理总页数准入、不隐式OCR。V2代码已接内部路径，Chat默认仍V1，待全链路资源/浏览器合同完成并统一验收再默认切换。记录只说明实现状态，不提供当前功能通过结论。
