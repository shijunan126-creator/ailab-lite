# ADR 0033：上下文纪元、绝对压缩区间与运行过程快照

状态：已采纳（2026-11-04，本地实施，未合并/部署）。设计来源：[上下文压缩 HLD v4](../design/2026-11-03-context-compaction-hld.md)，本 ADR 记录与 HLD 的差异及实施中的产品决定。部分取代 [ADR 0030](0030-prefix-stable-model-requests.md) 之后由[前缀缓存设计](../design/2026-10-31-prefix-cache.md)描述的压缩规则（85% 触发、固定保留最近两组、自由文本摘要）。

## 背景

压缩、重建和跨轮继承原先各自实现：触发 85%、Work 保留最近两组、摘要是自由文本且只在 `capability_discovery==1` 时结构化；安全压缩点只是调用顺序的隐含结果；后台任务句柄在压缩后对模型不可见；`ContextSummaryFrame.revision` 无法表示运行内压缩。历史过程页依赖 30 天后会被 GC 的 RunEvent。

## 决定

1. **上下文纪元**：RunCheckpoint 记录 `context_abi`（`CONTEXT_ABI_VERSION`）与运行内 `context_epoch`。纪元内只追加；替换前缀的边界（compacted / model_changed / context_abi_changed / access_revoked / rebuilt）与 checkpoint CAS、边界事件在同一 API 事务内提交，事件上报不决定纪元。ABI 不同则重建；旧 checkpoint 无 ABI 时沿用原兼容检查后补写。
2. **结构化检查点**：三条路径（运行内、跨轮父上下文、历史重建）统一 `ContextSummary` 结构与确定性序列化；来源句柄只来自 API 维护的类型化元数据（运行祖先、授权附件、验证记录），不从消息文本或 JSON 中提取。程序拥有的运行状态（后台任务句柄、交付、计划、待处理文件）和已加载模块导航各以确定性块渲染，不进入语义 JSON。
3. **安全压缩点**：显式协议组解析与 `validate_safe_compaction_point`；未配对调用/结果拒绝压缩；关闭的后台 exec 句柄可压缩且不杀进程；`run_subtasks` 作为一个单元。
4. **触发与压缩后大小**（取代 HLD §28 的 50–60%）：触发为模型窗口 W 的 90%。压缩或任何重建后的整份请求目标 10K–48K（瞄准 30K），硬上限 64K；小窗口缩放 `L=min(10K,.15W)`、`U=min(48K,.55W)`、`H=min(64K,.75W,T−1,W−输出预留−余量)`。下限不填充。三条路径共用一个规划/校验器，校验实际待激活请求而非预测值；可在管理后台调整。
5. **保留优先级**：固定前缀 → 有界运行状态 → 当前用户输入与本轮全部插话（含图片）→ 最近完整协议组（含其图片）→ 有界摘要（≤6K）→ 更早原文组。计划、交付、模块导航、记忆各有块预算；交付防重始终由运行时完整执行。工具结果在首次写入时按整批（参数、结果、图片、拒绝预留）准入，批次上限由 H 扣除必须内容推得；整份技能文件要么完整放入，要么返回结构化无法放入，不截断。
6. **唯一的超上限例外**：只有当前用户输入本身使请求超过 H（其余必须内容可放入 H）时才放行，且须低于 T；运行内保留最近完整组，跨轮可不保留历史原文组。固定前缀/运行状态/摘要超限一律暂停。
7. **失败合同**：摘要截断、传输错误、非法 JSON、未知来源、容量不足都变为不自动恢复的 `ContextPause`，旧纪元保持权威，保留存活后台任务的租约（受原有 TTL/最长寿命约束）；同一不可压缩输入以摘要指纹去重，不重复付费。
8. **计数以供应商实际值为准**：每次模型调用返回的 `prompt_tokens` 作为锚点存入 checkpoint；当前大小 = 最近锚点 + 之后新增内容的估算。压缩后候选中已发送部分按锚点差值计价，只估算新生成的摘要/状态块。估算器只用于增量与无锚点情形；去掉原“系数只增不减”的进程内校准。不引入分词器。
9. **运行过程快照**：`run_process_snapshots`（迁移 0050）在运行停止时于 API 事务内物化 ProcessView（版本独立，当前 V2）；`GET /v1/runs/{id}/process` 与运行详情同授权；事件 GC 须有覆盖到最高序号的快照；补快照按页扫描；事件序号以快照为下界，GC 后不复用。快照不进入模型上下文。
10. **阈值迁移**：迁移 0051 只把持久化值恰为 0.85 的平台设置改为 0.90，记录所有权以便降级时只还原自己写入的值。

## 不做

不加召回控制器、当前会话 RAG、向量库、多级摘要树、逐轮滚动摘要；不为提高缓存命中放宽权限或暴露额外工具；95% 只作诊断区，不是第二套摘要。

## 后果

- 每次真实压缩/重建带来一次可预期的冷启动未命中，之后严格追加。升级后旧对话按原字节继续，不因升级强制重建。
- 历史过程不再依赖 30 天事件保留；迁移前已被 GC 的事件无法恢复。
- 成本与证据见[实施记录](../../progress/updates/2026-11-04-context-hld.md)。
